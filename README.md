# Hugo & Márcia — Pré-visualização do convite

Pré-visualização pública, adaptada a telemóvel, do convite de casamento de Hugo e Márcia (21 de maio de 2027).

## Abrir no telemóvel

Depois de ativar o GitHub Pages, aceder a:
https://erycafernandees.github.io/hugo-marcia-preview/

## Ativar GitHub Pages

1. Abrir **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolher **Deploy from a branch**.
3. Selecionar **main** e pasta **/(root)**.
4. Clicar em **Save**.

O site funciona apenas como pré-visualização: o RSVP não guarda respostas, e os nomes dos convidados utilizados para testar são fictícios. Não colocar listas reais de convidados nem informação sobre alergias neste repositório público.
